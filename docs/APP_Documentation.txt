- Instalaciones Realizadas -

Instalar Node.js LTS desde la pagina oficial de node
Instalar expo en el fronted
Escoger el template en blanco
Insttalar las dependencias para react dom, screens, navigation y el safe area context
Iniciar el proyecto con expo para prueba de correcta instalación
Instalar PostgreSQL y pgAgent, configurar la base de datos incluyendo usuario en contraseña
Crear dentro del proyecto la estructura de carpeta y los archivos a utilizar
Configurar dentro de los archivos lo necesario para el funcionamiento correcto de las tecnologias a utilizar
